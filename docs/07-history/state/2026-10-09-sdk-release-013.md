# SDK 0.13.0 / SOV 0.6.76 — current release state

**Verified 2026-10-09.** This snapshot supersedes the June extraction snapshot for current SDK status. Dated designs, audit reports and testing entries retain their original evidence.

## Published components

- **SDK 0.13.0**, MIT: public `yevgetman-sov-sdk-0.13.0.tgz` and `SDK-SHA256SUMS` in [SOV v0.6.76](https://github.com/yevgetman/sov-releases/releases/tag/v0.6.76). SHA256: `813aa74ef79b3f31db30d2b5b2382594f5fa7984ef2df40ca8d6af0eece7748c`.
- **SOV CLI/gateway 0.6.76**, proprietary: five platform binaries, separate `SHA256SUMS`. Immutable release source/tag: `7076729a77df8378cfd41f0bfaa350583818842b`.
- **Protocol 0.1.0**, MIT: independent wire types/client package. Its version did not change in this cut. The public SDK asset does not include a separate protocol release asset.
- Public distribution is a GitHub release tarball. The source repository is public. npm registry queries for SDK/protocol returned E404 on this check; install the released tarball. See [SDK install](../../../packages/sdk/README.md#install) and [publishing boundaries](../../../PUBLISHING.md).
- Supported SDK engines: **Node >=20.19.0 / Bun >=1.2.0**. Wrapper CI uses Bun 1.3.13; release compilers use Bun 1.4.2. These are different from the SDK support floor.

## Delivered

PRs #17–#22 merged. Issues #10–#14 are closed: stream readers close, incomplete responses fail, child deadlines include queue/lock waiting, reservations release on resolution failure, and terminal return joins started tools.

The SDK supplies an optional injected context-management port, bounded validated reductions, one overflow retry, custom capability profiles, native-child policy narrowing, shared tree budgets and child usage. It supplies a bounded in-process session work queue with cancellation and joined shutdown. It supplies no built-in summarizer, durable worker lease, database, deployment or OS sandbox. [Host lifecycle](../../04-extending/host-session-lifecycle.md) and [SDK security](../../../packages/sdk/SECURITY.md) state those boundaries.

OpenRouter Anthropic prompt caching shipped in SOV 0.6.72. MCP tool images also landed on 2026-08-25 (`4bee673`), through `ToolResult.newMessages`; `tool_result.content` remains a string. Backlog #63/#64 are resolved.

## Consumers and release pins

[Consumer contract](../../05-conventions/consumer-contract.md) separates library consumers from gateway clients:

- **Kernel runtime / kernel-sweep** pins SDK 0.13.0 for `TurnLogRecord` / `TurnLogSink`. The pin is merged and listed in draft runtime **0.50.68**; that runtime has not been published by this work.
- **Agent Casa / real-estate-agent-runtime** is an existing private SDK consumer. Its committed checkout `521a2ee` still pins vendored SDK **0.9.2**. Its typecheck and 1,193 tests passed with the candidate 0.13.0 tarball in an isolated snapshot. This proves compatibility for that revision, not an installed upgrade or current customer activity.
- **Kernel Mac app** uses SOV CLI/gateway rather than importing the SDK. CLI **0.6.76** is merged into its source pin and draft Mac **0.72.88** manifest. Neither Mac nor Kernel runtime was released or installed by that pin change.
